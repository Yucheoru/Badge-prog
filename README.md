# Badge-prog

大学内の多文化交流スペース **L-cafe** の教職員向けに制作した、
**オープンバッジ授与対象者を自動判定する** デスクトップアプリです。

参加記録の名簿（Excel）を入力すると、活動時間を集計し、
バッジ（Gold / Silver / Bronze）を獲得できる対象者を自動で判定して
名簿として出力します。従来は手作業で行っていた集計・判定を自動化しました。

## 背景・目的

L-cafe では活動への参加時間に応じてオープンバッジを授与しています。
参加者ごとに時間を合算し、プログラム種別ごとの基準と照らし合わせて
対象者を選ぶ作業は手間がかかり、ミスも起きやすいものでした。
本プログラムは、名簿を読み込むだけでこの判定を自動化し、
教職員の負担を軽減することを目的としています。

## 主な機能

- Excel 名簿の読み込みと活動時間の自動集計
- プログラム種別ごとの基準によるバッジ判定（Gold / Silver / Bronze）
- バッジ登録日より前の参加記録を除外して集計
- 結果を色分け付き Excel で出力（バッジ色分け・0.5時間セルの強調）
- 対象外データを別シートに分離
- ファイル選択・実行・ログ表示ができる GUI（Tkinter）

## バッジ判定基準（累計活動時間）

| プログラム種別 | Bronze | Silver | Gold |
|----------------|--------|--------|------|
| JCPP Learner   | 10h    | 20h    | 30h  |
| JCPP Provider  | 15h    | 30h    | 45h  |
| その他（既定） | 15h    | 30h    | 45h  |

※ バッジ登録日より前の参加日は集計対象外です。

## 入力ファイル形式（Excel）

| シート | 内容 |
|--------|------|
| `participation_ALL_clean` | 学籍番号・氏名・参加日・活動時間（0.5 / 1） |
| `OpenBadge_all_clean`（任意） | 登録日・メールアドレス（学籍番号＋プログラム名で紐付け） |

## 出力ファイル形式（Excel）

| シート | 内容 |
|--------|------|
| `結果` | プログラム名・学籍番号・氏名・メール・登録日・獲得バッジ・合計時間・参加日 |
| `除外データ` | 判定対象外となったレコード |

- バッジは Gold / Silver / Bronze で色分け表示
- 0.5時間の参加は水色セルで強調

## 使用技術

- **言語:** Python
- **GUI:** Tkinter
- **データ処理:** pandas
- **Excel 入出力・装飾:** openpyxl

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `main.py` | 集計・バッジ判定・Excel 出力のロジック（`process()`） |
| `main_gui.py` | Tkinter による GUI。ファイル選択・実行・ログ表示 |
