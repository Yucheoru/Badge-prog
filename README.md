# Badge-prog

大学内の多文化交流スペース L-café で、オープンバッジの授与対象者を判定するためのツールです。
以前は職員の方が参加記録の名簿を見ながら手作業で時間を合計していましたが、
その集計と判定を自動化しました。Python を入れていない職員の PC でも使えるよう、Windows 用の EXE もビルドできるようにしています。

## 判定のしかた

学生ごと・プログラムごとに参加時間を合計し、次の基準でバッジを決めます。
バッジ登録日より前の参加は数えません。

| プログラム | Bronze | Silver | Gold |
|---|---|---|---|
| JCPP Learner | 10h | 20h | 30h |
| JCPP Provider | 15h | 30h | 45h |
| その他 | 15h | 30h | 45h |

プログラム名は名簿によって接頭辞や空白が違うことがあるため、キーワードの部分一致で判定しています。

## 入力（Excel）

- `participation_ALL_clean`（必須）: 学生番号、氏名、参加日、結果統合（1 = 参加、0.5 = 半分参加、0 / 空欄 = 対象外）、`badge_status`（プログラム名）、`exclude_reason`（任意）
- `OpenBadge_all_clean`（任意）: 学生番号、プログラム名、オープンバッジ登録日、メールアドレス、卒業/Gold フラグ

列名は完全一致でなくても、キーワードを含んでいれば読み取ります。

## 出力（Excel）

- `結果`: 学生ごとの合計時間、取得バッジ、参加日の一覧。バッジは色分けし、0.5 時間の参加日は水色にします。
- `卒業_Gold`: 卒業/Gold フラグが 1 の学生（結果シートとは分けて出力）
- `除外データ`: 結果統合が 0 以下・空欄だった行

実行ログの最後に、入力行数と振り分け先の合計が一致するかの検算を表示します。

## 使い方

```bash
pip install -r requirements.txt
python main_gui.py                      # GUI
python main.py 入力.xlsx 出力.xlsx       # コマンドライン
```

`master` に push すると GitHub Actions でテストを実行し、Windows 用 EXE をビルドします（Actions の Artifacts からダウンロード）。

## テスト

```bash
pip install pytest
pytest
```

## 注意

名簿には個人情報が含まれるため、Excel ファイルはリポジトリに置かないでください（`.gitignore` で除外しています）。
